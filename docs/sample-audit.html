5. Paying for cloud services above the free 10 percent

ACCOUNT · costs $741/mo

Why: Cloud services used 690.0 credits (16% of compute); 247.0 credits were billed after the daily adjustment.

Fix: Usually caused by very frequent tiny queries, heavy SHOW / metadata calls from tools, or complex compilation. Find the top query types by CREDITS_USED_CLOUD_SERVICES and batch or cache them. Snowflake docs

SELECT query_type, warehouse_name, COUNT(*) AS n,
       SUM(credits_used_cloud_services) AS cs_credits
FROM SNOWFLAKE.ACCOUNT_USAGE.QUERY_HISTORY
WHERE start_time >= DATEADD('day', -30, CURRENT_TIMESTAMP())
GROUP BY 1, 2 ORDER BY cs_credits DESC LIMIT 20;

13. Queries spilling to remote storage

TRANSFORM_WH · costs $4,350/mo

Why: 240 GB spilled to remote storage. Remote spilling can make queries many times slower, and slow queries cost credits.

Fix: Find the spilling queries (BYTES_SPILLED_TO_REMOTE_STORAGE in QUERY_HISTORY). Reduce the data they process, or move just those jobs to a larger warehouse. Snowflake docs

SELECT query_id, LEFT(query_text, 200), bytes_spilled_to_remote_storage
FROM SNOWFLAKE.ACCOUNT_USAGE.QUERY_HISTORY
WHERE warehouse_name = 'TRANSFORM_WH' AND bytes_spilled_to_remote_storage > 0
ORDER BY bytes_spilled_to_remote_storage DESC LIMIT 20;

14. Warehouses with no spending cap

TRANSFORM_WH, COMPUTE_WH, ML_WH, LOADING_WH · costs $11,460/mo

Why: 4 warehouse(s) spending $11,460/month have no resource monitor. A runaway query or a forgotten loop has no ceiling.

Fix: Add a monthly monitor per warehouse at about 1.5x normal usage: notify at 80 percent, suspend at 100 percent. Requires ACCOUNTADMIN. Snowflake docs

CREATE RESOURCE MONITOR "FW_TRANSFORM_WH_MONTHLY" WITH CREDIT_QUOTA = 2180 FREQUENCY = MONTHLY START_TIMESTAMP = IMMEDIATELY
  TRIGGERS ON 80 PERCENT DO NOTIFY ON 100 PERCENT DO SUSPEND ON 120 PERCENT DO SUSPEND_IMMEDIATE;
ALTER WAREHOUSE "TRANSFORM_WH" SET RESOURCE_MONITOR = "FW_TRANSFORM_WH_MONTHLY";
CREATE RESOURCE MONITOR "FW_COMPUTE_WH_MONTHLY" WITH CREDIT_QUOTA = 2070 FREQUENCY = MONTHLY START_TIMESTAMP = IMMEDIATELY
